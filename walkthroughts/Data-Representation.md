* `Decimal (Base-10) System` - The standard positional numeral system that uses ten distinct digits (0–9) and positional values based on powers of ten.

* `Binary (Base-2) System` - A positional numeral system that uses only two digits, 0 and 1, serving as the foundational language for digital hardware and data processing.

* `Hexadecimal (Base-16) System` - A positional numeral system that uses sixteen distinct symbols (0–9 and A–F) to represent values, providing a compact, human-readable format for binary data.

* `Octal (Base-8) System` - A positional numeral system that uses eight digits (0–7) to represent numbers, often used in computing as a concise representation of binary numbers grouped into three bits.

* `Bit` - The most fundamental unit of digital data in computing, representing a single binary state of either 0 or 1.

* `Byte` - A basic unit of digital information storage composed of 8 contiguous bits, capable of representing 256 distinct binary values or a single character of text.

* `Hex Color` - A six-character hexadecimal code (#RRGGBB) used in digital systems and web design to define specific colors by specifying the intensity levels of red, green, and blue light on a scale from 00 to FF.
