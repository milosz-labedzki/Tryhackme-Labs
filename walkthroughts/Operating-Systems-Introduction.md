* `Operating System` - Core system software that manages computer hardware resources, memory, and running processes, providing an interface for user interaction and software execution.

* `Process Management` - The operating system function responsible for creating, scheduling, executing, and synchronizing active processes and threads.

* `Memory Management` - The allocation, tracking, and deallocation of physical and virtual memory spaces for active system programs and tasks.

* `File System Management` - The system responsible for organizing, storing, naming, securing, and retrieving files on storage media.

* `User Management` - The administration of user accounts, groups, authentication, authorization, and security permissions across the operating system.

* `Device Management` - The monitoring and hardware abstraction of peripheral and system devices using dedicated software drivers.

* `Authentication` - A security mechanism that validates identity claims through credentials, biometric scans, or multi-factor tokens.

* `Permissions` - Access control rules that define the precise read, write, and execution rights assigned to users, groups, and software applications.

* `Isolation` - A security boundary that confines processes to dedicated memory spaces, enforcing strict separation between user applications and the kernel.

* `System Protection` - Defensive safeguards that prevent unauthorized users or software from modifying core operating system files and critical configurations.

* `GUI` - Graphical User Interface that enables users to interact with software and operating systems through visual elements like icons, windows, and menus using mouse or touch input.

* `CLI` - Command Line Interface that enables users to execute tasks and interact with systems by typing text commands directly into a terminal or console prompt.

* `Kernel Space` - A privileged memory region reserved for running the operating system kernel, device drivers, and core functions with unrestricted access to system hardware.

* `User Space` - An isolated memory area where standard software applications execute with restricted privileges to maintain system safety and operational stability.
