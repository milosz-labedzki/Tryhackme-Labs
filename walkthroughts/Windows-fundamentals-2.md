* `psshutdown` - A command-line utility from the Sysinternals suite used to shut down, reboot, log off, or lock local or remote Windows systems.

* `System Tools` - A collection of operating system utilities used to monitor, configure, maintain, and troubleshoot system hardware, performance, and software resources.
 
* `Task Scheduler` - A built-in Windows component that enables the scheduling and automated execution of programs, scripts, or tasks at predefined times or in response to specific event triggers.

* `Task Scheduler Library` - A hierarchical repository within the Windows Task Scheduler that stores, organizes, and manages scheduled tasks created by the operating system, applications, and administrators.

* `Event Viewer` - A built-in administrative tool in Windows that enables users and administrators to view, filter, and analyze system, security, and application event logs for monitoring and troubleshooting.

* `Error` - An Event Log entry indicating a significant problem, such as a service failure or data loss, that impacts system functionality.

* `Warning` - An Event Log entry indicating a potential future problem or non-critical issue, such as low disk space, from which the system can recover.

* `Information` - An Event Log entry that describes the normal, successful operation of an application, driver, or system service.

* `Success Audit` - A security log entry recording a successful audited access attempt, such as a user successfully logging on to the system.

* `Failure Audit` - A security log entry recording a failed audited access attempt, such as an unauthorized logon or denied resource access.

* `Application Log` - A Windows Event Log that records events generated by applications and software, such as application errors or database events defined by developers.

* `Security Log` - A Windows Event Log that tracks security-relevant events, including successful/failed logon attempts, administrative privilege use, and resource auditing.

* `System Log` - A Windows Event Log that records events logged by core Windows system components and drivers, such as service failures or hardware errors during startup.

* `Custom Log` - An application-specific Windows Event Log created to isolate event data, manage log file sizing, and apply targeted ACL permissions.

*  `Device Manager` - A built-in Windows administrative component that allows users and administrators to view, configure, manage, and troubleshoot hardware devices and their associated driver software.

* `Storage` - A Windows system management component that allows administrators to configure, monitor, and manage physical drives, logical volumes, storage spaces, and file systems.

* `Disk Management` - A built-in Windows system utility used to view, create, format, shrink, extend, and delete drive partitions and manage physical and logical storage volumes.

* `Services` - Background processes in Windows that execute without a user interface to perform core operating system functions, manage network features, and run software tasks automatically.

* `resmon` - A built-in Windows system utility that provides real-time monitoring and detailed performance metrics for CPU, memory, disk, and network resources.

* `cmd` - The default command-line interpreter in Windows operating systems used to execute built-in commands, run batch scripts, and perform system administration tasks.

* `hostname` - A command-line utility used to display or set the system's network name.

* `whoami` - A command-line utility that displays the username of the currently logged-in user in the active shell session.

* `ipconfig` - A Windows command-line utility used to display current TCP/IP network interface configurations and refresh DHCP and DNS settings.

* `/?` - A command-line switch in Windows used to display help documentation, syntax guidelines, and available parameters for a specified command.

* `netstat` - A command-line network utility used to display active TCP/IP network connections, listening ports, routing tables, and detailed network interface statistics for troubleshooting and monitoring.

* `net` - A versatile Windows command-line utility used to manage local users, groups, network shares, system services, and active network connections.

* `regedit` - A built-in Windows system utility (Registry Editor) used to view, search, modify, export, and manage configuration keys and values within the Windows Registry.
