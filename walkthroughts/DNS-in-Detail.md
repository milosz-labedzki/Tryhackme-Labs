* `DNS` - Domain Name System; a hierarchical and decentralized naming system that translates human-readable domain names into numerical IP addresses required for network routing.

* `TLD` - Top-Level Domain; the highest level in the Domain Name System hierarchy located immediately after the root zone, representing the last segment of a domain name (e.g., .com, .org, .io).

* `Second-Level Domain` - The portion of a domain name located directly to the left of the Top-Level Domain, serving as the main brand or organizational identity of a website (e.g., "google" in google.com).

* `Subdomain` - An additional prefix added before the second-level domain to create distinct, logically separated sections under a primary domain name (e.g., "api" in api.example.com).

* `DNS Record Types` - Standardized resource formats stored within DNS zone files that dictate how specific domain request types should be parsed, mapped, or routed.

* `A Record` - Address Record; a foundational DNS resource record that maps a hostname directly to a 32-bit IPv4 address.

* `AAAA Record` - IPv6 Address Record; a DNS resource record that maps a hostname directly to a 128-bit IPv6 address.

* `CNAME Record` - Canonical Name Record; a DNS record that creates an alias by mapping one domain name to another primary domain name instead of an IP address.

* `MX Record` - Mail Exchanger Record; a DNS record that specifies the mail servers responsible for receiving incoming email on behalf of a domain, along with their priority ordering.

* `TXT Record` - Text Record; a multi-purpose DNS record used to store arbitrary human- or machine-readable text data, extensively utilized for domain ownership verification and email security protocols (SPF, DKIM, DMARC).
