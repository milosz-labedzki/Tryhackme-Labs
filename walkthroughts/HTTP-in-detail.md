* `HTTP` - Hypertext Transfer Protocol; an application-layer protocol used for transmitting hypermedia documents across the web via a stateless client-server architecture.

* `HTTPS` - Hypertext Transfer Protocol Secure; an extension of HTTP that encrypts communications using TLS/SSL to ensure data privacy, integrity, and authentication.

* `URL` - Uniform Resource Locator; a standardized web reference string that specifies the network location of a resource and the protocol used to access it.

* `GET Request` - An HTTP method used strictly to retrieve data from a specified resource without modifying server state or causing side effects.

* `POST Request` - An HTTP method used to submit data to a server for processing, typically resulting in state changes, database entries, or resource creation.

* `Put Request` - An HTTP method used to upload a payload that completely replaces the existing target resource at the specified URI, or creates it if it does not exist.

* `Delete Request` - An HTTP method used to request the permanent or logical removal of a specified resource from the server.

* `403-Forbidden` - An HTTP client error status code indicating that the server understood the request but refuses to authorize access due to insufficient permissions.

* `404 - Page not found` - An HTTP client error status code indicating that the server cannot locate the requested resource at the specified URL destination.

* `503 - Service Unavailable` - An HTTP server error status code indicating that the server is currently unable to handle the request due to temporary overload or scheduled maintenance.

* `Cookies` - Small client-side key-value data files stored by web browsers and transmitted with HTTP requests to maintain session state, authentication, and user preferences.
