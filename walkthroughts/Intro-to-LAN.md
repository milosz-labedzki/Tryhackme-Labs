* `LAN topologies` - The physical or logical arrangement of nodes, devices, and links within a Local Area Network.

* `Star topology` - A network structure where all endpoints connect independently to a single central hub or switch.

* `Bus topology` - A network layout where all nodes connect to a single central cable that acts as a shared transmission backbone.

* `Ring topology` - A network configuration where each device connects to two neighboring devices, forming a closed circular path for data traversal.

* `Switch` - A Layer 2 network device that inspects and forwards data frames between devices on the same local network using MAC addresses.

* `Router` - A Layer 3 network device that routes data packets between distinct IP networks based on logical destination IP addresses.

* `Subnetting` - The strategy of dividing a single IP network into smaller, logically segmented sub-networks to enhance routing efficiency and security.

* `Network Address` - An IP address used to identify an entire subnet, designated by having all host bits set to zero.

* `Host address` - An IP address assigned to a specific network interface on a device within a host range, enabling unique node identification.

* `Default Gateway` - The IP address of a router interface that local network devices use as an exit node to reach external networks.

* `ARP` - Address Resolution Protocol; a protocol used to map a known Layer 3 IPv4 address to its corresponding physical Layer 2 MAC address.

* `DHCP` - Dynamic Host Configuration Protocol; a network service that automatically assigns IP addresses, subnet masks, default gateways, and DNS settings to clients.
