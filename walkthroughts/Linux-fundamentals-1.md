# Linux Fundamentals - Part 1

* `whoami` - prints the current logged-in user name

* `echo [text]` - outputs the specified text to the terminal

* `pwd` - prints the absolute path of the current working directory

* `ls` - lists all files and directories in the current folder

* `cd [directory]` - changes the current working directory

* `cat [filename]` - displays the entire content of a file

* `grep [pattern] [filename]` - searches for a specific string or text inside a file

* `find [path] -name [filename]` - searches for files and directories in the filesystem

* `>` - redirects command output to a file (overwrites existing content)

* `>>` - redirects command output to a file (appends to the end of the file)

* `&` - runs a command in the background

* `&&` - chains commands together, executing the second command only if the first succeeds
