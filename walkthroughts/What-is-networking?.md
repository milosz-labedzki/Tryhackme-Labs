* `network` - A system of interconnected devices that exchange data and share resources using standardized communication protocols.

* `Internet` - A global system of interconnected computer networks utilizing the TCP/IP protocol suite to transmit data worldwide.

* `private network` - A network utilizing non-routable IP addresses (RFC 1918) for internal communication, restricted from direct access by the public Internet.

* `public network` - An open network infrastructure, such as the Internet, where connected endpoints use globally routable IP addresses to communicate publicly.

* `IP Addresses` - Unique numerical identifiers assigned to devices on a network to facilitate routing and addressing under the Internet Protocol (IPv4/IPv6).

* `Octet` - An 8-bit section of binary data, commonly representing one of the four decimal numbers separated by dots in an IPv4 address.

* `Mac Adresses` - Unique 48-bit hardware identifiers assigned to Network Interface Cards (NICs) for Layer 2 (Data Link) communication.

* `ICMP` - Internet Control Message Protocol; a Layer 3 protocol used by network devices to send error messages, operational signals, and diagnostic data.

* `Ping` - A diagnostic utility that sends ICMP Echo Request packets to a target IP address to test reachability and measure round-trip time (RTT).
