* `Motherboard` - The main printed circuit board (PCB) in a computer that connects and facilitates communication between core system components, including the CPU, RAM, storage, and peripheral expansion cards.

* `CPU` - The Central Processing Unit that executes program instructions, performs arithmetic and logical operations, and coordinates data flow between computer hardware components.

* `RAM` - High-speed, volatile primary memory used by a computer to temporarily store data and program instructions for quick access by the CPU during operation.

* `Storage (SSD/HDD)` - Non-volatile secondary storage media used for permanent data retention, consisting of high-speed flash-based Solid State Drives (SSDs) and traditional magnetic platter Hard Disk Drives (HDDs).

* `Network Adapter` - A hardware component that enables a computer to communicate with other devices over a wired or wireless local network and connect to the internet.

* `Power Supply (PSU)` - A hardware component that converts high-voltage alternating current (AC) from a power outlet into regulated, low-voltage direct current (DC) required by internal computer components.

* `Graphics Card` - A dedicated expansion card featuring a GPU and VRAM that processes, renders, and outputs visual data and 2D/3D graphics to a display device.

* `Input/Output` - The peripheral hardware devices, ports, and interfaces that allow a computer system to receive data and commands from users (Input) and convey processed results outward (Output).

* `Press Power Button` - The physical user action that closes a signal circuit on the motherboard, triggering the power supply to deliver electrical power to all computer components.

* `Firmware Start (UEFI/BIOS)` - The execution of motherboard low-level software that initializes basic hardware interfaces and prepares the system to manage the boot sequence.

* `Power-ON Self Test (POST)` - A diagnostic routine performed by the firmware to verify that core hardware components, such as the CPU, RAM, and graphics device, are functioning properly.

* `Select Boot Device` - The firmware evaluates configured priority settings to locate a connected storage device containing a valid bootable partition or media.

* `Initiate Bootloader` - The firmware loads the bootloader code from the targeted storage drive into memory and transfers system execution control to it to launch the operating system.
