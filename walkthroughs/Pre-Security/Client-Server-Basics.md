* `Request` - A message sent by a client to a server to ask for data or an action.


* `Response` - A message sent by a server back to the client with the requested data or result.


* `Protocol` - A set of rules that defines how devices communicate. Both sides must understand the protocol.


* `Port` - A number that identifies a communication endpoint used by a network service. Example: port 80 for HTTP and port 22 for SSH.


* `DNS` - Translates domain names, such as tryhackme.com, into IP addresses so computers can communicate with servers.


* `HTTP/HTTPS` - HTTP is a protocol used for communication between web browsers and web servers. HTTPS uses TLS encryption to protect data during transmission.


* `GET/POST` - HTTP methods. GET is commonly used to retrieve data from a server. POST is commonly used to send data to a server, for example through a login form. POST does not encrypt data by itself.
