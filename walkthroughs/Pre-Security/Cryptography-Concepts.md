* `Cryptography` - The practice and study of securing communication and data against adversarial access through mathematical encoding techniques and protocols.

* `plaintext` - Unencrypted, human-readable data or text in its original, intelligible form before passing through an encryption process.

* `ciphertext` - The scrambled, unreadable output produced by running plaintext through an encryption algorithm using a specific cryptographic key.

* `key` - A parameter or secret piece of data used by cryptographic algorithms to transform plaintext into ciphertext or vice-versa.

* `algorithm` - A well-defined, step-by-step mathematical procedure or set of rules used to perform encryption, decryption, or hashing operations.

* `caesar cipher` - A simple substitution cipher that encrypts plaintext by shifting every letter down the alphabet by a fixed integer value.

* `symmetric encryption` - A cryptographic method where the exact same secret key is shared and used for both the encryption and decryption of data.

* `asymetric encryption` - A cryptographic method that utilizes a mathematically linked key pair: a public key for encryption and a private key for decryption.

* `HTTPS` - Hypertext Transfer Protocol Secure; an application-layer protocol that combines HTTP with TLS/SSL encryption to secure client-server web communications.

* `padlock icon in the address bar` - A visual browser interface indicator confirming that the current web connection is encrypted via TLS/SSL and backed by a valid digital certificate issued by a trusted CA.
