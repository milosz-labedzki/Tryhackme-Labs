* `Virtualization` - Running multiple virtual machines on one physical computer to save hardware costs and resources.


* `Hypervisor` - Software that creates and manages virtual machines by sharing physical CPU, RAM, and storage resources.


* `Lab Machine` - An isolated virtual machine used to test software and practice safely without risking the main host.


* `Container` - An isolated environment that runs an application with its required dependencies.


* `Container Images` - Templates containing an application and its dependencies. One image can be used to create multiple containers.


* `Network Ports` - Numbers used to direct network traffic to the correct service on a computer. Common ports: 22 (SSH), 80 (HTTP), 443 (HTTPS).
