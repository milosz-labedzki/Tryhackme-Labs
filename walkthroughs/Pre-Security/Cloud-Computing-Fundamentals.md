* `Public Cloud` - Cloud infrastructure managed by a provider and shared by multiple customers. Each customer has a separate environment.


* `Private Cloud` - A cloud environment dedicated to one organization. It can be managed by the organization or an external provider.


* `Hybrid Cloud` - A combination of private and public cloud environments used for different tasks.


* `IaaS` - The provider manages physical servers and virtualization. The customer manages the operating system, applications, and configurations.


* `PaaS` - The provider manages the infrastructure and platform. The customer focuses on building and managing applications.


* `SaaS` - A ready-to-use application provided over the internet. The provider manages the application and infrastructure, while the user simply uses the service.


* `EC2` - Amazon's cloud service for running virtual servers called instances. Users can install operating systems, run applications, and manage their virtual machines.


* `EBS` - Persistent block storage that can be attached to an EC2 instance. It can be detached and attached to another compatible instance to access stored data.
