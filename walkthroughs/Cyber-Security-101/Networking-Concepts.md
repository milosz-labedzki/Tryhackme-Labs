* `OSI MODEL` - Open Systems Interconnection model; a conceptual seven-layer framework that standardizes telecommunication and computing system network functions.

* `Physical Layer` - Layer 1 of the OSI model, responsible for transmitting raw bit streams over physical transmission media using electrical, optical, or radio signals.

* `Data Link Layer` - Layer 2 of the OSI model, responsible for node-to-node frame transmission, physical MAC addressing, framing, and local network error detection.

* `Network Layer` - Layer 3 of the OSI model, responsible for logical host addressing (IP addresses), packet forwarding, and path selection across interconnected networks.

* `Transport Layer` - Layer 4 of the OSI model, responsible for end-to-end communication management, data segmentation, flow control, and error recovery.

* `Session Layer` - Layer 5 of the OSI model, responsible for establishing, managing, synchronizing, and terminating persistent communication sessions between applications.

* `Presentation Layer` - Layer 6 of the OSI model, responsible for data syntax translation, data formatting, compression, and encryption/decryption.

* `Application Layer` - Layer 7 of the OSI model, provides network interface protocols directly to end-user applications and software services.

* `TCP/IP Model` - A practical four-layer networking framework (Network Access, Internet, Transport, Application) that serves as the foundation for the global Internet.

* `Routing` - The process of identifying and selecting paths across one or more networks to forward IP packets from a source to a destination host.

* `UDP` - User Datagram Protocol; a connectionless, lightweight Transport Layer protocol designed for fast, low-latency transmission without delivery guarantees.

* `TCP` - Transmission Control Protocol; a connection-oriented, reliable Transport Layer protocol that guarantees ordered, error-checked, and flow-controlled data delivery.

* `Encapsulation` - The process of wrapping data from a higher OSI layer with header and trailer control metadata as it moves down through lower network layers.

* `Telnet` - An unencrypted, legacy application-layer network protocol used to provide bidirectional interactive text-oriented CLI communication over a network.
