* `CyberChef` - A web-based cyber multi-tool developed by GCHQ for performing cryptographic, encoding, decoding, parsing, and data manipulation operations directly in the browser.

* `Operations` - The left-side pane in CyberChef containing the searchable list of all available data processing tools categorized by functional domain.

* `Recipe` - The middle pane in CyberChef where users sequence and configure multiple operations to execute sequentially on the input data.

* `Input` - The top-right pane in CyberChef where users paste, type, or upload raw data to be processed by the active recipe.

* `Output` - The bottom-right pane in CyberChef displaying the processed result generated after running the input through the configured recipe.

* `From Morse Code` - An operation that converts dot-and-dash Morse code sequences into readable plaintext characters.

* `URL Encode` - An operation that translates special or non-ASCII characters into percent-encoded strings (e.g., `%20`) for safe transmission in web requests.

* `To Base64` - An operation that converts raw text or binary data into an ASCII string representation using 64 printable characters.

* `To Hex` - An operation that converts input data into hexadecimal (base-16) byte representation.

* `To Decimal` - An operation that converts raw binary, hex, or ASCII character values into equivalent base-10 numerical values.

* `ROT13` - An operation that applies a basic substitution cipher by shifting alphabetic characters 13 positions forward in the alphabet.

* `Extract IP addresses` - An operation that uses regular expressions to scan input data and extract all matching IPv4 and IPv6 addresses.

* `Extract URLs` - An operation that scans input text using regex patterns to isolate and list all web resource links.

* `Extract email addresses` - An operation that parses input text to identify and extract strings matching standard email address syntaxes.

* `From UNIX Timestamp` - An operation that converts numeric POSIX timestamps (seconds/milliseconds elapsed since Jan 1, 1970) into human-readable date and time strings.

* `From Base64` - An operation that decodes Base64-encoded ASCII text back into its original plaintext or binary data.

* `URL Decode` - An operation that parses percent-encoded URL sequences (e.g., `%20` or `%3D`) back into unencoded characters.

* `From Base85` - An operation that decodes Base85 (Ascii85) encoded text back into raw binary or string format, commonly used in PDF files and Git blobs.

* `From Base58` - An operation that decodes Base58-encoded strings (used in Bitcoin addresses and IPFS to eliminate visually ambiguous characters) back to raw bytes.

* `To Base62` - An operation that encodes data into an alphanumeric string using 62 printable characters (0-9, a-z, A-Z), widely used for identifier shortening.
