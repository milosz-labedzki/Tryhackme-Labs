* `Security Misconfigurations` - A vulnerability category arising from improperly configured security controls, default credentials, exposed cloud storage, verbose error messages, or unneeded active services.

* `Software Supply Chain Failures` - Security risks and breaches resulting from compromised third-party dependencies, malicious package updates, or vulnerabilities introduced via software build pipelines.

* `Cryptographic Failures` - A category of security flaws occurring when sensitive data is inadequately protected in transit or at rest due to weak encryption algorithms, improper key management, or plain text transmission.

* `Insecure Design` - A risk category representing architectural and design flaws where security controls, threat modeling, and defensive patterns were missing or improperly conceived during system planning.
