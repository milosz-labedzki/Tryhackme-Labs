* `set` - Displays, creates, or modifies environment variables in the active Command Prompt session.

* `ver` - Displays the official version number of the installed Windows operating system.

* `systeminfo` - Displays comprehensive system configuration details, including OS build, hardware specs, boot time, and installed hotfixes.

* `more` - Displays output or file contents one screenful at a time to prevent rapid scrolling.

* `help` - Lists available Windows CMD commands or provides detailed syntax and usage instructions for a specified command.

* `cls` - Clears the Command Prompt terminal screen buffer of all previously displayed text.

* `ipconfig` - Displays essential TCP/IP network configuration values, including IPv4/IPv6 addresses, subnet masks, and default gateways.

* `ipconfig /all` - Displays exhaustive network configuration details, including MAC addresses, DHCP server info, lease times, and DNS servers.

* `ping` - Sends ICMP Echo Request packets to a target IP or domain to verify network reachability, packet loss, and round-trip latency.

* `trecert` - Commonly intended as `tracert` (Trace Route); tracks and displays the hop-by-hop router path and latency of IP packets to a destination network host.

* `nslookup` - Interrogates DNS servers to resolve hostnames to IP addresses or query specific resource record types.

* `netstat` - Displays active TCP/UDP connections, listening ports, network interface statistics, and routing tables.

* `cd` - Change Directory; displays the path of or navigates to a different working directory.

* `dir` - Displays a list of files, subdirectories, and associated metadata within the current or specified path.

* `tree` - Generates a visual, tree-like diagram representing the directory hierarchy of a drive or path.

* `mkdir` - Make Directory; creates a new directory or nested folder structure at a specified path.

* `type` - Displays the raw text contents of a file directly inside the terminal window.

* `move` - Relocates one or more files from a source directory to a target directory, or renames directories.

* `del` - Permanently deletes one or more specified files from disk storage.

* `copy` - Duplicates one or more files from a source location to a designated target destination.

* `tasklist` - Displays a list of all currently active operating system processes, along with their Process IDs (PID) and memory usage.

* `chkdsk` - Check Disk; scans a specified disk volume for file system logical errors and physical bad sectors.

* `driverquery` - Scans and displays a list of all installed hardware device drivers along with their status and properties.

* `sfc /scannow` - System File Checker; scans all protected Windows system files and replaces corrupted or modified files with a cached copy.
