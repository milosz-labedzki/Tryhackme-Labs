* `SIEM` - Security Information and Event Management; a comprehensive security platform that collects, aggregates, normalizes, and analyzes log data across an enterprise infrastructure to detect threats and assist incident response.

* `Host-Centric Log Sources` - Systems and endpoints (e.g., Windows workstations, Linux servers) that generate logs reflecting local operational activities such as process execution, user logins, registry edits, and file access.

* `Network-Centric Log Sources` - Devices and security controls (e.g., firewalls, routers, IDS/IPS, proxies) that log communication traffic flowing across network boundaries, including IP connections, VPN sessions, and DNS queries.

* `Answers Nowhere` - A security analysis challenge where log data is decentralized, unformatted, and scattered across disparate systems, making it difficult or impossible to construct a clear timeline or derive actionable security intelligence.

* `Features of SIEM` - Core operational capabilities provided by a SIEM platform, including log aggregation, data normalization, cross-source correlation, automated alerting, visualization dashboards, and regulatory compliance reporting.

* `Centralized Log Collection` - The process of gathering, ingesting, and consolidating event logs from disparate network devices and hosts into a single, unified repository.

* `Normalization of Logs` - The transformation of raw log data from various vendor formats into a standardized structure and unified key-value schema (e.g., mapping IP fields across different firewalls to a uniform `src_ip` field).

* `Correlation of Logs` - The automated process of cross-referencing and linking events from multiple disparate log sources to identify complex attack patterns, lateral movement, or suspicious activity sequences.

* `Real-time Alerting` - An automated SIEM mechanism that continuously evaluates incoming streams of normalized logs against rule engines to trigger immediate notifications when suspicious threshold triggers or threat indicators are met.

* `Dashboards and Reporting` - Visual interface modules within a SIEM that aggregate key security metrics, alert trends, and compliance posture into customizable graphs, charts, and exportable documentation.

* `Event Viewer` - A native Windows administrative utility (`eventvwr.msc`) used to browse, query, and manage local operating system, security, application, and system logs.
