* `Threat Emulation` - Executing realistic cyber attacks targeting live infrastructure based on actual adversary TTPs.


* `Emulation vs Simulation` - Emulation precisely mimics a specific threat actor, while simulation uses synthetic tests to mimic general attack behaviors.


* `Behavior-Focused Detection` - Security focus on actions rather than file signatures or hashes, as signatures can be easily altered by attackers.


* `MITRE ATT&CK` - A comprehensive knowledge base mapping real-world adversary Tactics, Techniques, and Procedures (TTPs).


* `Atomic Red Team` - Small, highly repeatable test scripts mapped to MITRE ATT&CK techniques used to validate security controls and find detection gaps.


* `TIBER-EU Framework` - A European framework for threat intelligence-led red teaming designed to test critical financial infrastructure and real incident response without notifying defenders.
