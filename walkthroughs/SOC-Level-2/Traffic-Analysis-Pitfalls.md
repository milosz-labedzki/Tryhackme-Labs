* `What QUIC Is` - A modern transport protocol running over UDP that offers fast connection setup and built-in encryption.


* `Detecting QUIC` - Identifying QUIC traffic by monitoring UDP port 443 instead of standard TCP port 443.


* `NetFlow` - Network telemetry providing connection metadata like IPs, ports, and data volume without storing full packet payloads.


* `FortiGate` - An enterprise Next-Generation Firewall used for advanced traffic inspection, application control, and threat defense.


* `Sysmon EventID 3` - Windows logging event that records network connection creations by processes, useful for spotting suspicious outbound connections.
