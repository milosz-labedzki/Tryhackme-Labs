- `Preparation` - Setting up security tools, processes, and response plans beforehand to prevent attacks or minimize damage when they happen.


- `Incident Response` - The structured process of reacting to, managing, and mitigating a security breach.


- `Event` - Any observable occurrence in a system or network recorded as a plain log with no assigned risk level.


- `Alert` - A notification triggered by suspicious event activity that requires further investigation to rule out false positives.


- `Incident` - A confirmed security event that poses a real threat to the organization and requires immediate action.


- `NIST SP 800-61` - A widely recognized framework that provides guidelines for managing cybersecurity incidents from preparation to post-incident analysis.


- `CSIRT` - Computer Security Incident Response Team: a specialized group responsible for responding to, managing, and resolving security incidents.


- `Detection Gap` - The time or visibility gap between when a threat occurs and when security systems or analysts actually detect it.
