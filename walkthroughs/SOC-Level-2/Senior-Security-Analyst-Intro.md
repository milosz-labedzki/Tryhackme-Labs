* `Senior Security Analyst (SOC L2)` - Advanced security analyst responsible for deep-dive investigations, complex threat hunting, incident response escalation, and understanding adversary TTPs.

* `General Security Tasks` - Core SOC duties including triage, log analysis, alert validation, root-cause analysis, and incident remediation.

* `Attacker Mindset` - Defensive approach leveraging offensive security knowledge (Red Teaming) to anticipate adversary behavior, correlate attack indicators, and structure investigations using frameworks like MITRE ATT&CK and the Cyber Kill Chain.
