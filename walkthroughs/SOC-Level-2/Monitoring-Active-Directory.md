* `Account Creation (Event ID 4720)` - A new user account was created in Active Directory.


* `Account Enabled (Event ID 4722)` - A previously disabled user account was enabled and activated.


* `Password Reset Attempt (Event ID 4724)` - An attempt was made to reset a user account password by an administrator or privileged entity.


* `Account Disabled (Event ID 4725)` - A user account was manually disabled.


* `Account Locked Out (Event ID 4740)` - A user account was locked out after reaching the maximum allowed failed logon attempts, indicating a potential brute-force attack.


* `Global Group Member Added (Event ID 4728)` - A user was added to a domain-wide global security group.


* `Local Group Member Added (Event ID 4732)` - A user was added to a machine-level or domain-local security group.


* `Universal Group Member Added (Event ID 4756)` - A user was added to a forest-wide universal security group, granting permissions across all trusted domains in the forest.


* `Successful Logon (Event ID 4624)` - A user or service successfully authenticated and logged on to the system.


* `Failed Logon (Event ID 4625)` - An authentication attempt failed, which can indicate incorrect credentials, typos, or brute-force activity.
