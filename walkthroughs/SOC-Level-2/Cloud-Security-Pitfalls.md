* `Cloud Security Pitfalls` - Cloud resources are directly exposed to the internet, so misconfigurations can easily lead to data leaks and attacks compared to local office servers.


* `What Is Cloud` - Renting external infrastructure and computing power to share data and scale resources without overloading local computers.


* `IaaS` - Renting raw virtual machines and networking where you manage the OS and configuration.


* `PaaS` - The cloud provider manages the OS and runtime environment, while you focus on deploying your application code.


* `SaaS` - Buying and using fully managed software applications directly from the provider.
