* `Network Discovery Detection` - The process of identifying and monitoring scanning activities used by threat actors to map out hosts, open ports, and services across a network.

* `External Scanning Activity` - Reconnaissance probes originating from outside the network perimeter targeting public-facing IP addresses and infrastructure.

* `Internal Scanning Activity` - Reconnaissance probes conducted from inside the trusted network, usually signaling a compromised host or lateral movement.

* `head` - A Linux command-line utility used to display the first few lines of a file or output stream.

* `cut` - A Linux command-line utility used to extract specific columns or fields from lines of text based on a defined delimiter.

* `Horizontal Scanning` - A scanning technique where an attacker checks a single port across a wide range of multiple IP addresses.

* `Vertical Scanning` - A scanning technique where an attacker checks multiple ports on a single specific target IP address.

* `Ping Sweep` - A network discovery method that sends ICMP echo requests across an IP range to identify live hosts.

* `TCP SYN Scans` - A stealthy port scanning technique that sends TCP SYN packets to detect open ports without completing the full three-way handshake.

* `UDP Scan` - A port scanning method that sends connectionless UDP packets to identify open non-TCP services like DNS, DHCP, or SNMP.
