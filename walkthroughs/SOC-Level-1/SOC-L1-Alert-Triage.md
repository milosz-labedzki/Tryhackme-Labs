* `SIEM system` - Security Information and Event Management system; a centralized platform that aggregates, correlates, and analyzes security event log data across an enterprise to detect active threats.

* `EDR or NDR` - Endpoint Detection and Response or Network Detection and Response; specialized security monitoring solutions targeting host activity/processes (EDR) or raw network traffic packets and flows (NDR).

* `SOAR System` - Security Orchestration, Automation, and Response system; a platform that standardizes and automates incident response playbooks and integrates disparate security tools to speed up mitigation.

* `ITSM System` - IT Service Management system; software platforms (e.g., ServiceNow, Jira) used to create, track, manage, and document IT service tickets, asset inventories, and security incident workflows.

* `Filter the alerts` - The process of refining incoming security alerts by filtering out known false positives, benign activity, or low-priority events using specific criteria like IP address or event ID.

* `Sort by severity` - The practice of organizing queued security alerts by priority level (e.g., Critical, High, Medium, Low) to focus analyst response efforts on the highest-risk threats first.

* `Sort by time` - Ordering alerts chronologically (e.g., newest first or oldest first) to establish event sequences, understand incident timelines, or process alert queues in order of arrival.

* `Alert Triage` - The preliminary investigation phase where a security analyst assesses raw alerts to determine their legitimacy, potential impact, priority, and necessary escalation or closure steps.
