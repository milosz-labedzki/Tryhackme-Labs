* `Kill chain` - A step-by-step framework that describes the sequential stages of a cyberattack from initial planning to final execution.

* `Threat Modelling` - A structured process used to identify, evaluate, and prioritize potential security risks and attack vectors in a system.

* `Unified Kill Chain` - A modern framework that unifies traditional kill chains into 18 phases across three main stages: Infiltration, Propagation, and Action on Objectives.

* `Reconnaissance` - The phase where an attacker gathers useful information about a target to identify potential security weaknesses.

* `Weaponization` - Combining malicious exploit code with a payload to create a functional cyber weapon aimed at the target.

* `Social Engineering` - Manipulating people into sharing confidential data, giving away credentials, or breaking security protocols.

* `Exploitation` - Taking advantage of a software vulnerability or system weakness to execute unauthorized code on the target.

* `Persistence` - Techniques used by an attacker to keep access to a system even after reboots, updates, or credential resets.

* `Defence Evasion` - Tactics used by attackers to hide their presence and avoid detection by security tools and logging systems.

* `Command & Control` - Creating a covert communication link between a compromised system and an attacker-controlled server to send commands.

* `Pivoting` - Using a compromised host as a jump point to reach and attack other systems in an internal network.

* `Discovery` - Exploring a newly compromised network or system to map out resources, users, and installed software.

* `Privilege Escalation` - Gaining higher-level permissions, such as Administrator or root, on a compromised machine.

* `Execution` - Running malicious scripts, commands, or binary files on a target system.

* `Credential Access` - Stealing credentials like passwords, hashes, and session tokens to gain legitimate system access.

* `Lateral Movement` - Moving sideways through a network from system to system to reach high-value targets.

* `Collection` - Gathering target files, sensitive data, and business records from compromised systems before theft.

* `Exfiltration` - Stealing gathered data by transferring it out of the target network to an external server.

* `Impact` - Actions taken to disrupt, corrupt, encrypt, or destroy system availability and operations.

* `Objectives` - The primary end goals of an attack, such as stealing data, making a financial profit, or causing service outages.
