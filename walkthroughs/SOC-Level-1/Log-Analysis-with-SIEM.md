* `SIEM` - Centralized platform that collects, aggregates, and correlates log data across an infrastructure for real-time threat detection and compliance auditing.

* `Authentication Logs` - Identity verification records tracking user logins, logouts, privilege escalations, and failed authentication attempts across systems.

* `System Logs` - OS-level event logs capturing kernel operations, system service statuses, hardware events, and daemon activities.

* `Web Log Sources` - Server logs (e.g., Apache, Nginx, IIS) capturing HTTP request details, response status codes, user agents, and URL parameters.

* `Host-Based Log Sources` - System and application logs generated directly on endpoints (e.g., Windows Event Logs, Sysmon, auth.log, syslog) providing granular visibility into host activity.

* `Network-Based Log Sources` - Network device records (e.g., firewall logs, IDS/IPS alerts, NetFlow, DNS queries, proxy logs) monitoring traffic flow and network perimeter activity.

* `Web-Based Log Sources` - Specialized access and error logs generated by web applications, WAFs, and web servers detailing application-layer HTTP traffic and attacks.
