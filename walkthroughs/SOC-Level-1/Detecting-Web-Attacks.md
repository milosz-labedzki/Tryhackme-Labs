* `Client-Side Attacks` - Attacks that execute inside the target user's web browser, relying on vulnerabilities like Cross-Site Scripting (XSS) or malicious links.

* `Server-Side Attacks` - Attacks targeting vulnerabilities directly on the back-end web server or database, such as SQL Injection or Command Injection.

* `Attacks in Logs` - Malicious activity revealed in web access logs by searching for suspicious HTTP requests, payload strings, and abnormal status codes.

* `Attacks in Network Traffic` - Malicious web payloads and abnormal request patterns identified by inspecting raw HTTP/HTTPS packets in network captures.

* `FFUF` - Fuzz Faster U Fool; a fast command-line web fuzzing tool used to discover hidden web directories, files, and URL parameters.

* `WAF` - Web Application Firewall; a security system that filters and monitors HTTP traffic to block web attacks before they reach the web server.

* `WAF (syntax)` - Direct rule logic used to inspect and drop malicious HTTP traffic: If User-Agent contains "sqlmap" then BLOCK.
