* `Components of a Web Service (Application, Web Server, Host Machine)` - The three structural layers of a web service: the application code running the logic, the web server software delivering content, and the host machine running the OS.

* `Web Servers` - Software (like Apache or Nginx) or hardware responsible for accepting incoming HTTP/HTTPS requests from clients and serving web content.

* `Protecting the Application` - Securing web application code using input validation, output encoding, safe coding practices, and regular updates to prevent flaws like XSS or SQL injection.

* `Protecting the Web Server` - Hardening web server software by disabling unused modules, configuring safe SSL/TLS settings, restricting administrative interfaces, and applying vendor patches.

* `Protecting the Host Machine` - Securing the underlying operating system by disabling unneeded background services, enforcing strict firewall rules, managing user access, and keeping the system updated.

* `Security Tips for All Three Components` - General defense strategies applied across every layer, including enforcing the principle of least privilege, automating software updates, and enabling logging.

* `CDN` - Content Delivery Network; a distributed network of proxy servers that caches static web content near users to speed up load times and protect origin servers from DDoS attacks.

* `Web Application Firewall (WAF)` - A specialized security filter that inspects and analyzes HTTP/HTTPS traffic between the Internet and a web application to block malicious requests.

* `Antivirus (AV)` - Security software installed on the host machine to scan, detect, quarantine, and eliminate malware or malicious files.
