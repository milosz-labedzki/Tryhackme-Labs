* `Phishing` - A social engineering attack where attackers impersonate trusted entities to trick victims into revealing sensitive data, clicking malicious links, or downloading malware.

* `Anatomy of an Email Address (domain/username)` - The standard email structure consisting of a local username (identifying the user) and a domain name (identifying the mail server host), separated by the `@` symbol.

* `SMTP` - Simple Mail Transfer Protocol; a network protocol used by mail client software and servers to send and route outgoing email messages across networks.

* `POP3` - Post Office Protocol 3; an email retrieval protocol that downloads messages from a server to a single local device and usually deletes them from the server.

* `IMAP` - Internet Message Access Protocol; an email retrieval protocol that keeps emails stored on the server so users can sync and view them across multiple devices.

* `Email Headers` - Hidden metadata attached to an email that contains critical technical details, such as sender/recipient addresses, routing servers, timestamps, and authentication signatures.

* `Email body` - The core section of an email containing the actual message text, HTML styling, embedded links, and attachments sent to the recipient.

* `Types of phishing` - Variations of phishing attacks categorized by targeting style or communication medium, including Spear Phishing (targeted), Whaling (high-profile targets), Smishing (SMS), and Vishing (voice calls).
