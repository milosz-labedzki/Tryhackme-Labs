* `EDR` - Endpoint Detection and Response; a security solution that continuously monitors end-user devices to detect, investigate, and mitigate advanced cyber threats.

* `Features of EDR` - Core operational capabilities of an EDR platform, centered around continuous endpoint visibility, threat detection analytics, and real-time response actions.

* `Visibility` - The continuous recording and tracking of all endpoint events (processes, files, registry, network connections) to ensure complete operational transparency across hosts.

* `Detection` - The analytical process of identifying malicious behaviors, known indicators of compromise (IOCs), and anomalies from collected endpoint telemetry.

* `Response` - The set of actions available to contain and remediate threats on a host, such as process termination, file quarantine, or network isolation.

* `How an EDR works` - A three-phase operational cycle consisting of continuous endpoint data collection (Telemetry), real-time behavioral analysis (Detection), and active threat mitigation (Response).

* `Telemetry` - The operational data gathered by an EDR agent on a host, including process trees, network sockets, API calls, file system changes, and registry edits.

* `Detection` - The evaluation phase where an EDR correlates gathered host telemetry against threat intelligence feeds, rule engines, and behavioral models to surface alerts.

* `Response` - The execution phase where threat mitigation actions are applied automatically or manually to isolate compromised systems and neutralize malicious activity.
