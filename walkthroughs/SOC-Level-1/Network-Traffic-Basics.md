* `DNS Tunneling` - A technique that encodes non-DNS data inside DNS queries and responses to bypass firewalls and establish covert communication.

* `Application` - The top layer of the TCP/IP model that handles protocols used directly by software applications, such as HTTP, FTP, and DNS.

* `Transport` - The TCP/IP model layer responsible for host-to-host data transfer, segmentation, and flow control using protocols like TCP and UDP.

* `Internet` - The TCP/IP model layer that handles logical IP addressing, packet routing, and moving data across different networks.

* `Link` - The lowest layer of the TCP/IP model that manages physical hardware connections, MAC addresses, and local data framing.

* `Full Packet Capture` - The process of recording and saving all raw network traffic, including both packet headers and payload contents, for detailed analysis.

* `Network Tap` - A dedicated hardware device connected directly to a network cable that copies all passing traffic and sends it to monitoring systems.

* `Port Mirroring` - A network switch feature that duplicates traffic from one or more ports and forwards it to a specific port for security analysis.
