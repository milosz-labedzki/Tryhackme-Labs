* `Desktop` - The primary on-screen workspace where files, folders, and application shortcuts are visually displayed and managed.

* `Taskbar` - A system navigation bar that displays running applications, provides access to system tools, and houses quick settings and notification controls.

* `Desktop Icons` - Graphical shortcuts representing system utilities, folders, files, and frequently used applications for fast access.

* `Start Menu` - The central navigation hub for launching installed applications, accessing system settings, and managing power options like shutdown or restart.

* `Search` - A built-in utility that allows users to locate applications, files, system settings, and documents using keyword queries.

* `Task View` - A multitasking interface that displays all active windows and virtual desktops, enabling fast navigation between open tasks.

* `Pinned Applications and Folders` - Persistent shortcuts fixed to the taskbar or Start menu for one-click access to essential programs and directories.

* `Network and Audio Settings` - Quick-access controls in the system tray used to manage volume levels, sound outputs, and wired or wireless network connections.

* `Date and Time` - A system tray module displaying current clock and calendar data, with direct access to regional time and scheduling settings.

* `Notifications` - An alert center that aggregates system messages, app updates, and quick action toggles for operating system events.

* `Windows Update` - A built-in Microsoft maintenance service that automatically checks for, downloads, and installs security patches, system bug fixes, feature upgrades, and hardware driver updates to keep the operating system secure and stable.

* `Windows Security` - A centralized management dashboard built into Windows that integrates core protection services, including antivirus, firewall controls, account security, app and browser safety, and device health monitoring.

* `Task Manager` - A built-in Windows diagnostic utility that allows users to monitor real-time system performance, view active processes, manage startup applications, and terminate unresponsive programs.

* `Windows Defender Firewall` - A built-in host-based security feature that inspects and filters incoming and outgoing network traffic based on configurable security rules to protect the system against unauthorized network access and malicious threats.
